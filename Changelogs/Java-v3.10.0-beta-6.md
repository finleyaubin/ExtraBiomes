# ExtraBiomes for Java Edition v3.10.0 Beta 6
# Changes

## Biomes
- Mystic Forest: added the swamp-tagged vegetation, huge mushrooms, forest flowers, and tall grass that Bedrock's biome tags implied but the Java port was missing.
- The Netherlands Mutated: fixed farmland tilling onto ocean floors below sea level - it's now restricted to dry land.
- Jellyfish Fields: jellycoral no longer carpets the entire sea floor - scatter density greatly reduced.
- Grand Oasis: thinned out overcrowded palm trees, made surface fossils more common, and added a light dead bush scatter.
- Volcanic Moss Tundra: the lava river now renders as a continuous, wider channel instead of scattered specks; basalt pillars no longer overlap into lava/magma; the high-elevation moss floor no longer carves through magma banks; moss density now ramps smoothly with elevation instead of cutting off abruptly at a fixed height.

## Compatibility
- Fixed Create-compat windmill structures: kinetic blocks (belts, etc.) downstream of the Windmill Bearing were frozen in place after worldgen and never started spinning.

## Beta status
Still a beta release - the Java port remains newer and less battle-tested than the Bedrock addon, so please keep reporting anything that looks wrong on the GitHub issue tracker.
