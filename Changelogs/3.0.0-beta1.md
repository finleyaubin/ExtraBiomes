First beta of the 3.0.0 rewrite, bringing ExtraBiomes up to the 1.20.100 world generation format. This build focuses on getting biomes, wood, and blocks generating again after the format migration — expect rough edges.

### World Generation
- All biomes migrated to the new world generation format and generating again.
- Added the **Grand Oasis** (formerly Dry Oasis), with treasure-filled puddles; removed the old Desert Hills biome.
- Charred Forest, Cold Mesa and its variants, and Desert Bryce all generate correctly.
- Floating Jungle now spawns on mountain peaks; Fungle Jungle, Future Desert, and Glacier now generate.
- Moorlands now generates dry grass, double-tall grass, and mud alongside regular grass and podzol.
- Ice spikes hardcoded to also generate in Taiga Spikes biomes, since vanilla's feature had become locked to the vanilla biome.
- Fixed Mystic Forest and Lush Mesa colors and generation.
- Adjusted Shattered Swamp and Glacier generation frequency; sky city structures moved into their own folder; ice spikes can now sink 4-13 blocks into the ground.

### Blocks / Items
- All wood types updated to the new format, with corrected waterlogging behavior for transparent wood blocks.
- Palm doors, fences, trapdoors, and slabs now work; added a custom model for palm saplings.
- Palm leaves decay correctly (persistence after player placement still pending) and sapling growth now works.
- Fixed dense cloud brick slabs/stairs and several loot tables.
- Fixed all mushroom blocks (and scripted their loot tables) and updated all pebbles.
- Fixed stick pile rotation on placement.
- Nether ores render correctly again (a missing geometry component had left them invisible).
- All block textures renamed to the `extrabiomes_` prefix to avoid collisions with other add-ons.

### Mobs
- Renamed "Hopping Spore" to Hoppleshroom throughout the add-on.

### Misc
- Removed the UHD panorama subpack in favor of the SD panorama to save package size.
- Organized scripts into folders for maintainability.
- Removed several blocks from unintentionally showing up in menus/commands.
