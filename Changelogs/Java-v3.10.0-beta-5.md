# ExtraBiomes for Java Edition v3.10.0 Beta 5
# Changes

## Biomes
- Fixed several Sky City structures having wrong or missing block states from the NBT porting tools - affected stair, fence gate, button, door, and trapdoor rotations, glass panes/fences not connecting, and a stripped Sky Log id typo that dropped it from structures entirely.
- Fixed several Sky City buildings and the windmill structure missing their chest loot tables.

## Items & Blocks
- Fixed Palm Sapling's frond position being wrong (it looked disconnected from the trunk), and its leaf/frond faces not rendering when viewed from behind.
- Fixed Pebble and Mossy Pebble blocks dropping nothing when broken.

## Beta status
Still a beta release - the Java port remains newer and less battle-tested than the Bedrock addon, so please keep reporting anything that looks wrong on the GitHub issue tracker.
