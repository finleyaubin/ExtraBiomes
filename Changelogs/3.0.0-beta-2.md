### Sky City — Rework Begins
- Removed the old noise-based floating island system entirely: the sky city feature rules, the ore-features that scattered/shaved dense cloud, the orphaned "leveller" entity and structures, and `sky_city_placer.js` (the runtime hack that force-placed the city onto scattered clouds). The jigsaw structure set now drives placement on its own, so the city and its clouds can no longer desync.
- Added new sky city structures and got them generating via jigsaw placement (still detached from sky islands at this stage — full reattachment lands in the next beta).
- Made clouds bushier.

### Mobs
- Fixed dogs, which had appeared broken during testing — turned out to be a launcher issue rather than an add-on bug. Dog model restored and updated to the current format, including new personality features.
- Added client-side biome colors for Moorlands and Shattered Swamp.

### Blocks / Items
- Custom jungle moss implementation added, working around vanilla's moss feature becoming unavailable to add-ons.
- Fixed razor feather items (entity drops still pending).
- Fixed jellyfishing nets and jellyfish jam.
- Fixed throwable items (pebbles and bait).
- Fixed several item menu categories; all item textures now consistently use the `extrabiomes_` namespace.

### Scripting
- Migrated all legacy `/run` command events to the modern command-queue format.

### Behind the Scenes
- Multiple iterations on the CI/CD pipeline for building and publishing the `.mcaddon`.
