# ExtraBiomes for Java Edition - first release

This is the first public release of the Java Edition port of ExtraBiomes, targeting Minecraft 1.20.1 on both **Forge** and **Fabric**.

## What's included
- 26 new overworld biomes, ported from the Bedrock addon - frozen mesas, jellyfish-filled oceans, a floating Sky City, underground jungles, and more.
- New mobs to go with them: giant tortoises, jellyfish, piranhas, tree frogs, hoppleshrooms, harpies, worms, and puckoos, each with their own spawn eggs.
- New blocks, structures, and loot tables to match.
- World generation is powered by [TerraBlender](https://modrinth.com/mod/terrablender), which is a required dependency on both loaders.

## Beta status
This is a beta release. The Java port is newer and less battle-tested than the long-running Bedrock addon, so please report anything that looks wrong - missing biomes/features, generation issues, crashes - on the GitHub issue tracker.
