This folder contains 15 blank worlds with edited level.dat files, The edit to these files in the world allows the game to treat them as if the game is in version 1.17.42 which is the last version where true custom biomes were possible, This does mean that a lot of the 1.18/1.19/1.20 features won't be included, however, in my opinion, the support for ExtraBiomes and all the other broken custom biome mods outweigh these cons.

credit where it's due, this method was discovered and shown to me by https://mcpedl.com/user/jayly
