Bedrock-side fixes and new content alongside format updates for 1.20.30.

### Blocks / Items
- Added **Nether Diamond Ore**, the add-on's first ore block.
- Added dense cloud bricks.
- Added vanilla mining-speed tags and loot tables to existing blocks.
- Added biome tags for existing biomes.
- Started work on Razor Feathers and Frog's Legs items.

### World Generation
- Updated a range of format versions and the project's min engine version to account for changes in Bedrock 1.20.30.
- Fixed all known errors for Bedrock 1.20.30.

### Known Issues
- The creative inventory category for some Bedrock items is still incorrect.
