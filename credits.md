# AI Disclamer
Contains AI-generated code and text. this mod is ported from my almost entirely handmade Extrabiomes addon for bedrock, I started the porting proccess to forge by hand a few years ago, but claude code was used too generate unit tests for parity with the bedrock functunality which I then used with claude to help with porting the remaining bedrock code to java, and also translations.
